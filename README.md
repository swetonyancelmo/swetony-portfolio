# Portfólio — Swetony

Next.js (App Router) + TypeScript + Tailwind v4 + Framer Motion + next-themes.

## Rodar

```bash
npm install
npm run dev
```

## Onde editar o conteúdo

- `src/data/site.ts` — nome, cargo, frase, e-mail, GitHub, LinkedIn, domínio.
- `src/data/projects.ts` — cases (problema / solução / stack / resultado). Imagens em `public/projects/`.
- `src/data/stack.ts` — categorias e nível de profundidade de cada tecnologia.
- `src/components/About.tsx` — texto da trajetória e a mini-timeline.

## Deploy

Pronto para Vercel: importe o repositório e faça deploy sem configuração extra.
